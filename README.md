# weather-app

Plataforma moderna de notícias construida com  **HTML, CSS e  Javascript** focada em um visual limpo, responsivo e clean, com animação quando for sol o fundo sera com sol, chuva fundo com chuva, neve fundo com neve, e nuvem fundo com nuvem.

## Funcionalidades principais

- o aplicativo funciona com 1 tela desenvolvida, 1 tela de design e 1 tela  de texto.
- ira buscar a cidade e o fundo da tela ira mudar conforme a previsão, chuva fundo chuvoso, sol fundo ensolarado, neve fundo com neve, e nuvem fundo com nuvem
-tera informações de temperatura, dia da semana e dia do mês, temperatura atual, em caso de chuva ou neve ira falar se esta com chuva leve, forte ou moderada
- tera abaixo 3 informações extras como sensação climatica, umidade em %, e velocidade do vento em km/h


## Como rodar

Nenhuma dependência para instalar. Basta abrir o `index.html` no navegador.

**Recomendado:** use a extensão [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) do VS Code para evitar problemas com módulos JS.


-Node.js 20.0 ou superior
-Npm ou  yarn

### instalação

```bash
# Alternativa via terminal
npx http-server .
# ou
python -m http.server 8000
```
